# 关于我 / About Me

你好，我是**若风** 👋

一个在医学 AI 领域摸爬滚打的研究者，白天和模型打交道，晚上偶尔化身程序员搞点小项目。
代码写多了发现人生其实和调参差不多——方向对了，剩下的就是耐心。

这个博客是我的数字据点，记录那些值得留下来的东西：

- 📄 **文献阅读** — 把晦涩的论文翻译成人话
- 🔧 **技术笔记** — 踩过的坑，不想让你再踩一遍
- 🚀 **项目分享** — 从想法到代码的全过程
- 💭 **随机想法** — 不保证有深度，但保证真诚

内容不追求数量，只追求"写出来自己还愿意再看一遍"的质量标准。

## 🛠️ 关于本站

本站使用 **Astro** 框架构建，套用了颜值在线的 [Firefly](https://github.com/CuteLeaf/Firefly) 主题（基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发）。
追求轻量、快速、干净——就像好代码应有的样子。
